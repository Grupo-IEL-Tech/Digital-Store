# 🛍️ Digital Store

Projeto de uma loja virtual desenvolvido com **React + Vite**, com interface moderna e navegação entre produtos, categorias e pedidos.

## 🚀 Como executar o projeto na sua máquina

Siga os passos abaixo para baixar e executar o projeto localmente.

### 1. Pré-requisitos

Antes de começar, você precisa ter instalado:

- [Node.js](https://nodejs.org/)
- npm (instalado junto com o Node.js)
- Git

### 2. Clonar o repositório

Abra o terminal e execute:

```bash
git clone LINK_DO_REPOSITORIO_GITHUB
```

### 3. Entrar na pasta do projeto

Acesse a pasta clonada:

```bash
cd Digital-Store/client
```

### 4. Instalar as dependências

Execute o comando abaixo para instalar todas as dependências necessárias:

```bash
npm install
```

### 5. Executar o projeto

Após a instalação, inicie o servidor de desenvolvimento:

```bash
npm run dev
```

### 6. Acessar no navegador

Após iniciar o servidor, o Vite disponibilizará um endereço local, geralmente:

```text
http://localhost:5173/
```

Copie o endereço apresentado no terminal e abra no navegador.
